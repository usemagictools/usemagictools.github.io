Frequently Asked Questions

LLMs run entirely in VRAM (or system memory in CPU, which is extremely slow). Mac's unified memory serves as both system memory and high-bandwidth GPU memory (VRAM). This means a Mac Mini or Studio with 64GB or 128GB of RAM can load and run models (like 70B parameters) that would otherwise require multiple expensive NVIDIA GPUs on a PC.

The KV Cache (Key-Value Cache) stores the attention history of your conversation. As your context window grows (e.g., from 8k to 32k or 128k), the KV Cache memory footprint grows linearly. For larger models at high contexts, the KV Cache can consume more memory than the model weights themselves. Our calculator includes a realistic KV Cache estimation based on context length.

Yes! Extensive testing has proven that 4-bit quantization (Q4_K_M) retains over 95% of the original uncompressed (FP16) model's intelligence and coherence, while reducing the required memory footprint by more than 70%. It is the standard sweet-spot recommended for all local LLM deployments.

For running 70B parameters models like DeepSeek-R1 Distilled or Llama-3-70B, you need at least 48GB of unified memory (minimum) but 64GB or 128GB is highly recommended. The best-value machine is the Mac Studio with M2 Max (64GB) or Mac Studio with M2 Ultra (128GB), providing high memory bandwidth.
